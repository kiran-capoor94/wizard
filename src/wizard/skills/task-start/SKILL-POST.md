## Note Triggers

After any of these, call `save_note` before your next action:

1. You read ≥ 3 files tracing a single root cause
2. You chose between ≥ 2 implementation approaches
3. A test failed and you identified why
4. A finding contradicts what a prior note assumed
5. You are about to switch tasks or file areas

If none apply: do not save. Continue.

## Mental Model

Include `mental_model` when this is your 2nd+ note on the task and
`latest_mental_model` in this response was null. Omit otherwise — `save_note` will
synthesise one automatically.
